# Student Grade Management System

Data Structures assignment: a real-world application of arrays.

A class register for up to 100 students with marks in English, Mathematics and Science. The data is stored in fixed-size arrays (`names[100]` and `marks[100][3]`).

## Files

| File | What it is |
|------|------------|
| `index.html` | Web version of the same program, runs in any browser |

## Features

- Add a student with marks from 0 to 100 (invalid input is rejected)
- View the register with total, average and grade
- Search by name
- Delete a student (later students shift up one slot)
- Rank students by average
- Class statistics: class and subject averages, highest and lowest student

Grades: A is 80 and above, B 70 to 79, C 60 to 69, D 50 to 59, F below 50.


## Run the web version

Open `index.html` in a browser, or use the GitHub Pages link for this repository.
